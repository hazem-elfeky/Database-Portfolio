# Movie Database

## Overview

A relational database designed for a movie streaming and management platform. The database supports user accounts, movies, genres, actors, movie images, and favorite movies while maintaining a normalized and scalable architecture.

## Technologies

- MySQL
- SQL
- Relational Database Design
- ER Modeling

## Database Features

- User Management
- Movie Management
- Genre Management
- Actor Management
- Movie Images
- Favorite Movies
- Many-to-Many Relationships
- Normalized Database Structure

## Database Design

The database is designed using relational modeling principles with primary keys, foreign keys, and junction tables to efficiently manage many-to-many relationships between movies, genres, and actors.
